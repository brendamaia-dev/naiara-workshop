# Workshop Naiara Souza — página de vendas

Para editar no VS Code, abra esta pasta. A subpasta `assets` também contém as cinco imagens otimizadas, para futura edição.

Para publicar na Vercel: importe a pasta como projeto estático, sem framework e sem build. `index.html` está na raiz.
